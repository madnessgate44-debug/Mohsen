# Replica provenance

This branch is a source snapshot copied from the public repository
https://github.com/madnessgate44-debug/Firstborn at the time this workflow ran.

The original Mohsen files are preserved under `legacy-mohsen/`. Source workflow files are restored separately through the connected GitHub API because the Actions workflow token cannot push workflow-file changes.
The replication workflow is retained at `.github/workflows/replicate-firstborn.yml`
so the operation can be repeated from the Mohsen default branch.

This is a file snapshot, not a history-preserving Git fork. Git history,
repository settings, secrets, environment protection rules, and external
integrations are not copied.
